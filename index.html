Concept

A function is a reusable block of code that takes input, does work, and returns an output. It helps separate logic into neat pieces.

function average_marks(students):

Example

def average_marks(student_list):
    total = 0
    for student in student_list:

    return total / len(student_list)

print(average_marks(students))

Let's understand the code

  1. def average_marks(...): declares a reusable function.
  2. total += student["marks"] accumulates marks.
  3. return ... sends the final value back to the caller.

Lambda & Recursion

What you'll learn

  • Anonymous functions with lambda
  • When lambda is useful
  • Recursive functions
  • Base case vs recursive step

Why does this matter in Data Science?

Short transformations appear in sorting, filtering, and aggregations. Recursion is useful when a problem naturally breaks into smaller subproblems.

Concept

A lambda is a quick one-line function. Recursion means a function calls itself until it reaches a stopping condition. Both are compact ways to model logic.

Example

students = [{"name": "Aarav", "marks": 85}, {"name": "Riya", "marks": 72}]

# Lambda: convert marks to percentage-like label
score_label = lambda marks: "Pass" if marks >= 50 else "Fail"
print(score_label(85))

# Recursion: count down to zero
def countdown(n):
    if n == 0:
        return "Done"
    return countdown(n - 1)

print(countdown(3))

Let's understand the code

  1. lambda marks: ... creates a short function without a full definition.
  2. if marks >= 50 else "Fail" is a compact condition.
  3. countdown(n - 1) reduces the problem until it reaches the base case.

Try it yourself

🟡 Intermediate: Use a lambda to check if a score is above 80 and print either Top performer or Needs improvement.

status = lambda score: "Top performer" if score > 80 else "Needs improvement"
print(status(85))

Challenge

Write a recursive function that calculates the sum of a list of numbers without using a loop.

Common mistakes

  • Forgetting the base case in recursion.
  • Overusing lambda when a normal function would be clearer.
  • Calling a recursive function with values that never reach the stopping condition.

Data Science connection

Lambda expressions are common in sorting and filtering tasks; recursion appears in tree-like data structures and some algorithmic problems.

File Handling

What you'll learn

  • Read and write text files
  • Use relative and absolute paths
  • Write clean file logic
  • Persist student records

Why does this matter in Data Science?

Datasets often start as text files, logs, or saved outputs. File handling is the basic way scripts store and reuse data.

Concept

Files let programs keep data even after the program ends. Text files are easy to read and edit, and this is often the first step when creating a local dataset.

Example

with open("students.txt", "w") as file:
    file.write("Aarav,85\n")
    file.write("Riya,72\n")

with open("students.txt", "r") as file:
    for line in file:
        print(line.strip())

Let's understand the code

  1. with open(...) opens a file and closes it automatically.
  2. "w" means write mode; "r" means read mode.
  3. .strip() removes the newline to keep output tidy.

CSV & JSON

What you'll learn

  • Read CSV and JSON data

  • Write analysis outputs
  • Convert between data formats

Why does this matter in Data Science?

Most real-world datasets arrive as CSV or JSON. These formats are easy to inspect and parse, which is why they appear in almost every pipeline.

Concept

CSV stores table-like data in rows and columns. JSON stores nested data in a readable key-value structure. Both are widely used in data science and APIs.

Example

import csv
import json

students = [
    {"name": "Aarav", "marks": 85},
    {"name": "Riya", "marks": 72}
]

with open("students.json", "w") as f:
    json.dump(students, f)

with open("students.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "marks"])
    writer.writeheader()
    writer.writerows(students)

Let's understand the code

  1. json.dump stores Python data as JSON.
  2. csv.DictWriter turns records into table rows.
  3. fieldnames defines the column names.

Try it yourself

Exception Handling & Debugging

What you'll learn

  • try / except / finally
  • Handle invalid inputs gracefully
  • Debug common runtime errors
  • Make scripts more robust

Why does this matter in Data Science?

Real datasets contain missing values, weird strings, or broken files. Robust code handles unexpected issues without crashing the whole analysis.

Concept

Exceptions are errors Python raises at runtime. Instead of stopping the program abruptly, you can catch them, report useful messages, and continue safely.

Example

student = {"name": "Aarav", "marks": "N/A"}

try:
    score = int(student["marks"])
    print("Score:", score)
except ValueError:
    print("Invalid marks value. Please enter a number.")
finally:
    print("Validation complete.")

Let's understand the code

  1. try contains code that may fail.
  2. except ValueError catches a specific problem.
  3. finally runs no matter what happens.

Try it yourself

🟢 Beginner: Write code that handles a bad marks value and prints a friendly message.

marks = "abc"
try:
    print(int(marks))
except ValueError:
    print("Marks must be numeric.")

Challenge

Handle both a missing file and an invalid data value in one script.

Common mistakes

  • Using a broad except: without clarifying what failed.
  • Ignoring the type of exception.
  • Suppressing errors without giving useful information to the user.

Data Science connection

Bad sensor values, missing columns, and failed API responses are common in data projects. Defensive coding prevents your entire model workflow from collapsing.

What you'll learn

  • Encapsulation with simple examples

Why does this matter in Data Science?

Programs become easier to manage when real-world entities like students, datasets, or models are represented as objects rather than loose dictionaries and functions.

Concept

Object-oriented programming (OOP) groups related data and behavior together. A class defines a blueprint, and an object is a specific instance built from it.

Example

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def pass_status(self):
        return "Pass" if self.marks >= 50 else "Fail"

student = Student("Aarav", 85)
print(student.name)
print(student.pass_status())

Let's understand the code

  1. class Student: defines the blueprint.
  2. __init__ sets the object's initial state.
  3. pass_status() is a method that uses the object's data.

Iterators & Generators

What you'll learn

  • How iteration works in Python
  • Iterators and generator functions
  • Memory-efficient processing
  • Use in large datasets

Why does this matter in Data Science?

Large datasets don’t always fit comfortably in memory. Generators help process values one by one instead of loading everything at once.

Concept

An iterator provides values one at a time, and a generator creates them lazily. This is useful when you want to process data efficiently without storing everything in memory.

Example

def student_generator(students):
    for student in students:
        yield student

students = ["Aarav", "Riya", "Kiran"]
for student in student_generator(students):
    print(student)

Let's understand the code

  1. yield turns a function into a generator.
  2. Each value is produced one by one instead of all at once.
  3. for ... in ... consumes the values as they are generated.

Try it yourself

🟢 Beginner: Write a generator that yields the marks of students above 80.

def top_students(scores):
    for score in scores:
        if score > 80:
            yield score

print(list(top_students([72, 81, 88, 70])))

Challenge

Create a generator that reads a list of students and yields only names starting with the letter A.

Common mistakes

  • Using a list when a generator would be more efficient.
  • Forgetting that generators are consumed once.
  • Confusing iteration over a list with one-time generator output.

Data Science connection

Generators are ideal for processing large logs or datasets in chunks without consuming too much memory.

Decorators

What you'll learn

  • Wrap functions with additional behavior
  • Understand reusable code patterns
  • Use decorators for logging and validation
  • See why they matter in real codebases

Why does this matter in Data Science?

Decorators are used for logging, timing, validation, and access control. They help add features without modifying the original logic.

Concept

A decorator wraps a function and adds behavior before or after it runs. This is a pattern for extending functionality without rewriting the function itself.

Example

def log_function(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        result = func(*args, **kwargs)
        print(f"Finished {func.__name__}")
        return result
    return wrapper

@log_function
def average_marks(marks):
    return sum(marks) / len(marks)

print(average_marks([80, 72, 91]))

Let's understand the code

  1. log_function() defines a wrapper around another function.
  2. @log_function tells Python to use the wrapper.
  3. The wrapper logs activity before and after the original function runs.

Try it yourself

🟡 Intermediate: Create a decorator that prints the result of a student grade function.

def show_result(func):
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        print(f"Result: {result}")
        return result
    return wrapper

@show_result
def grade(score):
    return "Pass" if score >= 50 else "Fail"

print(grade(78))

Challenge

Write a decorator that validates that marks are numeric before running a function.

Common mistakes

  • Forgetting to return the wrapped function result.
  • Confusing decorators with simple loops.
  • Using decorators for very simple logic that doesn’t need wrapping.

Data Science connection

Decorators are common in frameworks for timing, logging, monitoring, and validation of functions used in experimental pipelines.

SQL with Python

What you'll learn

  • Create and query tables
  • Use SQL with Python
  • Filter results by conditions
  • Fetch summaries and top performers

Why does this matter in Data Science?

SQL is the language of relational data. Data scientists use it to filter, aggregate, and explore large datasets before analysis.

Concept

SQL lets you ask questions about structured tables. Python can send SQL statements to a database and then work with the returned results.

Example

import sqlite3

conn = sqlite3.connect("students.db")
cur = conn.cursor()
cur.execute("SELECT name, marks FROM students WHERE marks >= 80")
rows = cur.fetchall()
for row in rows:
    print(row)
conn.close()

Let's understand the code

  1. SELECT ... WHERE ... filters records using conditions.
  2. fetchall() retrieves every matching row.
  3. for row in rows loops through results.

Top performer

Write a function to return the student with the highest marks.

students = [{"name": "Aarav", "marks": 85}, {"name": "Riya", "marks": 72}, {"name": "Kiran", "marks": 91}]

def top_student(items):
    return max(items, key=lambda s: s["marks"])

print(top_student(students))

Grade distribution

Count how many students fall in each grade band.

students = [{"name": "Aarav", "marks": 85}, {"name": "Riya", "marks": 72}, {"name": "Kiran", "marks": 91}]

counts = {"A": 0, "B": 0, "C": 0}
for student in students:
    if student["marks"] >= 90:
        counts["A"] += 1
    elif student["marks"] >= 75:
        counts["B"] += 1
    else:
        counts["C"] += 1
